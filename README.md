# Student Management System

## 📌 Project Overview

The **Student Management System** is a menu-driven Python console application developed to manage student academic records.

The application allows users to add student details, calculate total marks and percentage, assign grades, check Pass/Fail status, find the topper, and display passed or failed students.

## 🛠️ Technologies Used

* Python
* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* User Input

## ✨ Features

1. Add Student Details
2. Calculate Total Marks
3. Calculate Percentage
4. Assign Grades
5. Check Pass/Fail
6. Display Student Details
7. Find Topper
8. Display Students Who Passed
9. Display Students Who Failed
10. Exit

## 📊 Student Information

The system stores:

* Student Name
* Roll Number
* Marks of 5 Subjects
* Total Marks
* Percentage
* Grade
* Result

The program calculates the total marks and percentage and then determines the student's grade and Pass/Fail result.

## 🎓 Grading System

| Percentage    | Grade |
| ------------- | ----- |
| 90% and above | A+    |
| 80% – 89%     | A     |
| 70% – 79%     | B     |
| 60% – 69%     | C     |
| 50% – 59%     | D     |
| 40% – 49%     | E     |
| Below 40%     | F     |
